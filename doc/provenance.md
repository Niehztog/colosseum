# Provenance

Where every file in this tree came from, at which commit, and under which
licence. Required by R-CORE-9, R-PROV-1, R-PROV-5 and R-LIC-5, and by Q1's
closure ("pin `b1f2c18f` and record it in `doc/provenance.md`" — re-pinned in
SPECS.md 1.4, see below).

Written at Phase 0. A later phase that imports a donor adds its row here in the
same commit as the import.

**RA2's pin moves in spec 1.16, from `cd0708b` to `d20e1ce`** — one commit, *"Build
with -Wall, and clear what it reports"*. Colosseum builds `-Wall -Wextra -Werror`,
so its four fixes are needed here or they get rediscovered, and §7 rule 7 makes
them ours. One of the four is **refused**: `barrel_touch`'s dead locals are
removed there because RA2 ships no `M_walkmove`, and this tree does
(`doc/reconciliation.md` R-66).

**The pin stays at `d20e1ce` in spec 1.30, and upstream is two commits past it.**
`ddba883` and `6b8d058` are both bug fixes, and the honest record is that this
tree already had two of their five halves — found by reading and by R-77, before
upstream reached them — and was missing three. The three are carried by hand
rather than by moving the pin, because moving it would claim the file was
re-derived from upstream when it was not: `arena.c` has diverged here by R-131,
R-134, R-135 and R-77's own different answer, and a merge would have to decide
between two fixes for the same defect rather than take one. What each half was
and where this tree stood is tabulated in `doc/reconciliation.md` R-139. The push
in `KillBox` is *not* one of them: upstream still adds the same vector to both
bodies, on both branches, so R-135 is new work.

**In spec 1.32 the pin still stays, and upstream is FOUR commits past it.**
`f90a8fb` and `811af42` are the two new ones and both are carried by hand for the
reason above: `f90a8fb`'s subject this tree had already fixed differently and
better, but its *measurement* is what exposed R-145 — a `pm_type` this port
translated to the wrong constant, which stopped the follow camera following — and
`811af42` is R-146, a fallback this tree's own note had argued against having.
Neither is a merge; both are tabulated in `doc/reconciliation.md` R-145..R-146.

**`q2pro`'s `feature/mission-packs` branch was REWRITTEN, and the pin therefore
names commits that no longer exist on it.** `c751d316` (README-only) and
`3ffc4642` ("Mission packs: portability and latent-bug fixes") are replaced by
`21381ffa`, `ecc00ad6` and `09d3c499`, with the fixes folded into the commits that
add the libraries — so the pinned objects are still resolvable in a clone that
has them and are no longer reachable from the branch. Recorded rather than
re-pinned, per R-PROV-5 clause 1: the content this tree took is unchanged for
`src/game` and `src/shared` (byte-identical between the two tips), and of the
`src/ctf`, `src/xatrix` and `src/rogue` changes only two were not already here
(R-147, R-148). The table in `doc/reconciliation.md` R-148's tail says where this
tree stood on each.

**Tourney's pin moves in spec 1.19, from `a8e30d0` to `1d8427e`** — two commits,
*"Fix the timer-unit defects the -w build hid, and turn -Wall on"* and *"Bound the
bot network message buffer"*. Both were named in §3.3 as work to carry, and §7
rule 7 makes them ours; taking the tip is cheaper and more honest than
cherry-picking their halves.

`gladiator-bot-restored` arrives in Phase 6, and only its two menu files —
`p_menulib.c` and `p_botmenu.c`, rows above. Its `botlib/` is **not vendored**:
R-BOT-3 loads the brain dynamically and R-BOT-4 says it is compiled from source
for whichever platform the game targets, so it stays a sibling repository and
`tools/botmatrix.sh` takes its path as `GLADDIR`. `tools/botabi.py` reads one
header out of it in `make check` and skips itself with a message when it is not
there.

Nothing from `gladq2_src` or `ugladq2` is in the tree. `gladq2_src/g_arena.c` is
refused outright by R-ARENA-1 (R-LIC-3, the RA2 Bot Support Routines).

**`colosseum/arena.cfg` is a new class of import and is recorded as one.** Every
other row above is either source or a file written here; this is a **data file
from a donor's distribution**, and it carries no copyright header — RA2's public
source tree has no licence text either, which is why the licence column says what
it says rather than naming one. What is known: RA2's *code* in this tree is
treated as id-derived GPL-2 under R-LIC-1, the file is data read by that code,
and R-LIC-4's net effect — **Colosseum is non-commercial** — covers the
distribution as a whole. R-LIC-3's notice about the RA2 Bot Support Routines is
untouched by this; that is a different file and is still absent. Flagged here
rather than settled, because a data file from a 1999 non-commercial mod is a
judgement the author should make knowingly.

## 3. A vendored header that is not closed under `#include`

`inc/common/bsp.h` line 24 includes `system/hunk.h`, and `inc/system/` is not
vendored — SPECS.md §5.2 lists three directories under `inc/` and that is what
was taken. This is harmless and deliberate: the game library never includes
`common/bsp.h`, so the dangling include is never followed. Recorded rather than
fixed, because vendoring a fourth directory would deviate from §5.2 and editing
the header would violate R-CORE-9's "never edited". If a later phase needs
`common/bsp.h`, vendor `inc/system/hunk.h` verbatim then and amend §5.2.
